# Security policy

Rivo handles an optional cookies jar and a plain-text configuration file, both inside the
app's private storage. Please do not paste a cookie export, a PO token, or a full `config`
into a public issue.

Report a vulnerability privately through GitHub's **Security advisories** tab on the
repository ("Report a vulnerability"). Include the app version, Android version, the flavor
(`fast` or `ytdlp`) and the smallest reproduction you have.

You can expect an acknowledgement within a few days. This is a volunteer project, so there
is no bug bounty and no formal SLA.

Out of scope: behaviour that is inherent to reading public site responses (for example a
site changing its markup), and requests to add DRM, age-gate or geo-restriction bypasses.

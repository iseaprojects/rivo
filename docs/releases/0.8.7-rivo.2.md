# Rivo 0.8.7-rivo.2

First release under the Rivo name.

Rivo is a YouTube app for Android that opens on a list: you type, it filters, you pick something.
It is a native port of yt-x 0.8.7, the terminal YouTube browser, with the same menus and the same
plain-text settings file, rebuilt so that phone things actually work.

## What you can do

- Watch up to 4K with sound, or keep listening with the screen off.
- Download videos, audio or a whole playlist; downloads continue in the background and survive a
  restart, with pause, resume and cancel.
- Keep recents, saved videos, playlists and subscriptions on the device.
- Choose a theme, a language, a page size and where files go, all from the same kind of menu.
- Use the Quick Settings tile, the recents widget, shortcuts or a Tasker broadcast to jump
  straight into a screen.

## Assets

- `rivo-0.8.7-rivo.2-fast.apk` (3.84 MB): YouTube only. Start here.
- `rivo-0.8.7-rivo.2-ytdlp.apk` (80.01 MB): the same app plus yt-dlp for other sites. Pick this
  one if you also browse outside YouTube.

Both are signed with the same key and install side by side with the debug build. Android 8.0 or
newer is required. Android will ask you to allow installing apps from outside Play.

## Notes

- Install a newer APK over this one to update. Uninstalling first would lose the local library.
- The in-app update check reads this repository's releases. While the repository is private, the
  check reports a failed request; that is expected.
- Upstream credit and the MIT notice are in the repository.

# Rivo 0.8.7-rivo.3

Two fixes, no new screens.

## The filter ignores accents

Typing `cancion` finds "Canción", `videoaula` finds "Videoaula", `uber` finds "Über". On a phone
keyboard an accent costs a long-press, so the filter now folds diacritics on both the query and
the text before matching. The same folding applies to the suggestions on the search screen, and
case folding no longer depends on the device locale (on a Turkish phone, `I` used to lowercase to
a dotless `ı` and break every match).

The ranking is unchanged: a prefix still beats a word boundary, and ties keep the order the
extractor returned.

## `CONFIG_DOWNLOAD_RETRIES` is honoured

The setting was documented as the retry budget of a download, but every transfer tried exactly
three times. It is now read from the config, clamped to 1–10, and shared by both tracks of a
merged download instead of restarting the count for the audio. There is a row for it in the
config screen ("Download retries": 1, 3, 5 or 10), because a value that only exists in the file
is a value nobody edits.

The backoff also stops growing at 8 seconds. With ten attempts configured, the old schedule would
have waited over two minutes between the last tries; a queued item should fail or succeed, not
outlast the user's patience. Set it to 1 on a metered connection if you would rather fail fast.

Nothing changes for anyone who left the value at 3.

## Also

- `docs/PARITY.md` now names the three upstream keys the app parses but does not act on
  (`CONFIG_STORYBOARDS`, `CONFIG_ENABLE_COLORS`, `CONFIG_NOTIFICATION_DURATION`) and says why, so
  an imported yt-x config keeps every line and nobody has to guess whether it is doing something.

## Assets

- `rivo-0.8.7-rivo.3-fast.apk`: YouTube only. Start here.
- `rivo-0.8.7-rivo.3-ytdlp.apk`: the same app plus yt-dlp for other sites.

Both are signed with the same key as `0.8.7-rivo.2`, so installing over it keeps your library,
your saved videos and your config.
